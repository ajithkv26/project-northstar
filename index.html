The column

This is the Sprint 0 reading test. Body text is Source Serif 4 at the body step, with a line height of 1.5. On a wide screen a full line is about 66 to 70 letters. On a phone the column is the screen width minus the inset, and the type size stays where it is.

The gap under this paragraph is the stack space. That interval is the body step. The page uses it again for the inset and for the gutter of the grid.

The grid

The page is four columns, and this text spans all of them. A later case study can put a figure on two columns and a caption on the other two. The gutter is the same stack space, so the grid does not add a second interval.
