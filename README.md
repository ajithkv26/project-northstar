# Project Northstar

A long-term product design project where the product is Ajith's professional portfolio. Audience: Design Directors, Heads of Design and product leaders. Goal: earn interviews by showing judgment, not just visuals.

## Build filter
Every improvement must make the portfolio easier to understand, easier to maintain, or more memorable. If it does none of these, don't build it.
